# Odin-Project-calculator

A basic calculator built with HTML, CSS, and JavaScript as part of
The Odin Project curriculum.

**Live demo:** https://chemseddineharaig.github.io/Odin-Project-calculator/

## Features

- Addition, subtraction, multiplication, and division
- Chained operations, evaluated left to right
- Decimal numbers (one decimal point per number)
- Percentage button
- Backspace and clear
- On/off button
- Division by zero shows an error message instead of crashing
- Keyboard support (numbers, operators, Enter, Backspace)
